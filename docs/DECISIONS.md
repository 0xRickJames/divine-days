# Divine Days — Decisions

- The game is an illustrated navigable web RPG, not a tile-based walking game.
- Primary targets are phones and computers.
- The initial UI uses React/Next.js rather than a canvas game engine.
- Realms contain four class buildings. Each building owns its shop, training, ceremony, and challenge functions.
- The four paths are Paladin, Barbarian, Rogue, and Mage.
- The four mortal realms are Shireville, Enchanted Forest, Underworld, and Nexus of Planes.
- The endgame has 21 gods: seven planetary Gates with Greek, Norse, and Egyptian encounters.
- Gate order is Moon, Mercury, Venus, Sun, Mars, Jupiter, Saturn.
- Odin is used rather than Woden.
- MongoDB Atlas is planned for persistent saves.
