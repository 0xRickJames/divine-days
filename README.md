# Divine Days

A mobile-first illustrated turn-based RPG. Players grow through four mortal realms, master four character paths, and ascend seven planetary gates to challenge 21 gods from Greek, Norse, and Egyptian pantheons.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy to Vercel

Import `0xRickJames/divine-days` into Vercel. The framework preset should be detected as Next.js; no custom build settings are required.

## Current prototype

- Responsive world map
- Shireville and its four class buildings
- Building-specific action screens
- Placeholder navigation for future character and inventory systems

See `docs/GAME_DESIGN.md`, `docs/WORLD.md`, and `docs/ROADMAP.md` for the current design.
